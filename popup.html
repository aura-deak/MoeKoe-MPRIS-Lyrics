运行异常排查

状态不对时按下面顺序排查

1. 安装依赖

Debian / Ubuntu 
sudo apt install python3-dbus python3-gi
Arch / CachyOS 
sudo pacman -S python-dbus python-gobject

2. 补上可执行位

若是从商城安装：

chmod +x ~/.config/moekoemusic/extensions/MoeKoe-MPRIS-Lyrics-*/bin/mpris-host

若是从压缩包安装：

chmod +x ~/.config/moekoemusic/extensions/moekoe-mpris/bin/mpris-host

3. 还不行

  • 在 设置 → 插件 → 插件管理 里确认已授权本地程序 mpris-host。
  • 确认 MoeKoe 已开启「API 模式」（默认 127.0.0.1:6520）。
  • 点下方「重新连接」和「刷新」，或完全退出并重启 MoeKoe。
