歌词传输模式

单歌词：MPRIS 侧只出现原文，Metadata 键 moekoe:lyrics 与信号字段 text。

单翻译：MPRIS 侧只出现译文，Metadata 键 moekoe:translation 与信号字段 translation。

歌词翻译：原文与译文同时传输，moekoe:lyrics 与 moekoe:translation 都会出现。

悬浮歌词操作说明

  • 关闭「鼠标穿透」后可直接拖动悬浮文字调整位置，松手自动保存（位置变为「自定义」）。
  • 开启「鼠标穿透」后悬浮窗不接收鼠标点击，点击桌面托盘里的悬浮歌词图标即可关闭；也可关闭穿透，再在悬浮文字上右键 → 退出。
  • 当前歌词为「纯音乐，请欣赏」时，悬浮窗自动隐藏不显示。
  • 改动显示设置后若悬浮窗没有及时更新，可点上方「立即重启」重新加载；完全退出并重启 MoeKoe 也能达到同样效果。
  • 曲目信息需先播放一次才会推送；暂停期间不再刷新进度，位置以最后一次校正为准。
  • 歌词来源是 MoeKoe 自己（含酷狗翻译），不联网取词；纯音乐行会按模式投影出「（本行无译文）」占位。
  • 悬浮窗基于 wlr-layer-shell，兼容 niri、Hyprland、Sway 等合成器；X11 会话不可用。
  • 悬浮歌词客户端由插件自动拉起，设 MOEKOE_MPRIS_NO_OVERLAY=1 可禁用。

运行异常排查

歌词不出、悬浮窗不出现时按下面顺序排查

1. 安装依赖

Debian / Ubuntu 
sudo apt install python3-dbus python3-gi gir1.2-gtk-4.0
Arch / CachyOS 
sudo pacman -S python-dbus python-gobject gtk4 gtk4-layer-shell

2. 补上可执行位

chmod +x ~/.config/moekoemusic/extensions/MoeKoe-MPRIS-Lyrics-*/bin/mpris-host

3. 还不行

  • 在 设置 → 插件 → 插件管理 里确认已授权本地程序 mpris-host。
  • 确认 MoeKoe 已开启「API 模式」（默认 127.0.0.1:6520）。
  • 点下方「重新连接」和「刷新」，或完全退出并重启 MoeKoe。
